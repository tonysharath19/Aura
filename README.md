## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or later)
- npm

### Installation

```bash
# Navigate to the backend directory
cd backend

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Frontend
Open `frontend/index.html` in your browser, or serve it via the backend at `http://localhost:3000`.
